Main Controller board:
Rasperry Pi 3B+
    - minimal Raspbian install with linux 4.9.59
    - sends G-code over serial to the Marlin mainboard

Motor Controller board:
Marlin mainboard
    - source: ~/Documents/Github/v-fpm/Marlin-2.1.2.4
    - connected to Pi over USB serial
    - configured for workspace XY moves and Marlin-side kinematics
    - probe wired to the controller board's probe input for G38.2 scans

Probe:
CNC 3D Touch Probe Edge Finder
    - NPN-NC
    - Connected to the Marlin board's probe input
    - Can optionally be mirrored to a Pi GPIO input for the web UI's live probe LED
